Detailed Description

This file contains a small drawing program.

This program allows the user to draw various shapes (horizontal line, vertical line, square, filled square, rectangle, filled rectangle) using a specified character. The user can also choose to draw random shapes or shapes defined in arrays. The program continues to run until the user chooses to quit.
